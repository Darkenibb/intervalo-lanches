# SOS Cantina Tech

Projeto escolar da equipe fictícia DevLanches. O objetivo é reduzir o tempo de espera na cantina com consulta ao cardápio, promoções e pré-reserva demonstrativa.

| CSS Master | Preencher |
| JavaScript Ninja | Preencher |
| Guardião do Git | Preencher |

## Como executar

Abra `dist/index.html` no navegador. O projeto usa HTML semântico, CSS com Grid e Flexbox, JavaScript e Git/GitHub. Os produtos e preços são fictícios. A pré-reserva é simulada no navegador e não envia pedidos à escola.

## Branches

- `main` — versão integrada.
- `feat/cardapio` — estrutura e conteúdo do site.
- `feat/layout-responsivo` — estilos para celular e computador.
- `feat/busca-carrinho` — busca, quantidades, total e pré-reserva.
- `feat/promocoes-semana` — destaque das ofertas semanais.

Em novas mudanças, crie uma branch a partir da `main` atualizada, faça commits pequenos e abra um pull request para revisão. Consulte [as respostas e o roteiro](APRESENTACAO.md).
